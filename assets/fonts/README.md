# Font sources

These are unmodified Latin WOFF2 subsets of the existing site fonts, hosted locally to avoid third-party stylesheet and font request chains.

- Geist, Google Fonts v5: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFWNOITd.woff2. Weight axis 100–900; the site uses 400–800. License: Geist-OFL.txt.
- Space Grotesk, Google Fonts v22: https://fonts.gstatic.com/s/spacegrotesk/v22/V8mDoQDjQSkFtoMM3T6r8E7mPbF4C_k3HqU.woff2. Weight axis 300–700; the site uses 600–700. License: SpaceGrotesk-OFL.txt.

The licenses were retrieved from the corresponding ofl/geist and ofl/spacegrotesk directories in the official google/fonts repository on 7 September 2026.
